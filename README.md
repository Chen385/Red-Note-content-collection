# 小红书内容采集助手

浏览器油猴脚本（Tampermonkey），在你本人打开的小红书笔记详情页上采集标题、正文与点赞 / 收藏 / 评论数据，结果保存在浏览器本地，支持复制到剪贴板和导出 CSV。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `小红书内容采集助手.user.js` | 油猴脚本本体，安装到 Tampermonkey 后在小红书笔记页运行 |
| `index.html` | 安装说明 + 本地演示页面，内嵌脚本源码，可一键复制 |

## 安装步骤

1. 在 Chrome / Edge / Firefox 应用商店安装 Tampermonkey 扩展。
2. 打开 `小红书内容采集助手.user.js`，复制全部源码；在 Tampermonkey 面板「添加新脚本」中粘贴并保存。也可以把 `.user.js` 文件下载后直接拖入浏览器。
3. 打开任意小红书笔记详情页，页面右侧会出现采集面板：
   - **采集内容**：抓取当前笔记的标题、正文和互动数据；
   - **复制到剪贴板**：复制全部已采集笔记；
   - **导出 CSV**：下载带 BOM 的表格文件，Excel 直接打开不乱码；
   - **重置数据**：清空本地已采集记录。

## 本地演示

直接打开 `index.html`，在演示面板填入标题、正文和互动数据，即可体验添加、复制、导出 CSV、清空的完整流程，演示数据只存在当前浏览器中。

## v1.6 优化记录

- 修复 `@namespace` 拼写错误，脚本元信息规范化。
- 剪贴板复制增加 `navigator.clipboard` 与 `execCommand` 回退，不再强依赖 `GM_setClipboard`。
- 互动数字解析支持逗号千分位与「万 / w」单位（如 `1.2万` → 12000）。
- 标题、正文渲染到面板前做 HTML 转义，避免注入。
- 话题标签去重；选择器补充 `#detail-title`、`#detail-desc .note-text` 等常见节点。
- CSV 字段统一转义，空值与边界情况补齐。
- 全程只读取当前页面可见内容，不包含登录绕过、验证码识别、Token 窃取或反爬对抗逻辑，不做批量抓取。

## 使用边界

- 脚本只能在你自己的浏览器、打开小红书页面时运行；外部网页受同源策略限制，无法跨域读取小红书内容。
- 采集结果仅保存在本地 `localStorage`，不上传服务器。
- 请遵守小红书平台规则与相关法律法规，仅用于个人研究、内容整理等正当用途，不要用于规模化批量抓取或数据转售。
- 平台页面结构更新后，若选择器失效，可在脚本内对应选择器位置按当前页面结构调整。
